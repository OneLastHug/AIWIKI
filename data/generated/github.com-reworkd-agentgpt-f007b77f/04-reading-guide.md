# 源码阅读指南

第一阶段只读核心入口，不要先看所有组件。建议从 `README.md`、`docker-compose.yml`、`next/package.json`、`platform/pyproject.toml`、`.env.example` 建立项目轮廓：这是一个 Node/Next.js 前端、Python/FastAPI 后端、MySQL 数据库、CLI 初始化和 Docker Compose 编排的项目。接着读 `next/src/pages/index.tsx`，重点看 `handleNewAgent`、`handlePlay`、`handleRestart`，它们说明用户目标如何变成一个正在运行的 `AutonomousAgent`。然后读 `next/src/services/agent/autonomous-agent.ts`，只关心 `run()`、`runWork()`、`addTasksIfWorklogEmpty()`、`pauseAgent()`、`stopAgent()`，这些函数是浏览器端任务循环的骨架。

第二阶段读 agent 的前端分层。`next/src/services/agent/agent-run-model.tsx` 解释生命周期、任务读取、任务状态更新如何落到 Zustand store；`next/src/stores/agentStore.ts`、`taskStore.ts`、`messageStore.ts` 分别保存 agent 状态、任务列表、消息列表。`next/src/services/agent/agent-api.ts` 是前后端调用边界，要重点看它保存 `runId`、发送 model settings、调用 `/api/agent/start`、`/api/agent/analyze`、`/api/agent/create` 的方式。再看 `next/src/services/stream-utils.ts`，理解 `/execute`、`/summarize`、`/chat` 为什么不是普通 JSON 响应。最后读 `agent-work` 目录，把 `StartGoalWork`、`AnalyzeTaskWork`、`ExecuteTaskWork`、`SummarizeWork`、`ChatWork` 串起来。

第三阶段读后端入口和 agent API。先看 `platform/reworkd_platform/__main__.py` 与 `web/application.py`，确认 Uvicorn、FastAPI app、CORS、startup/shutdown、router 注册。然后读 `platform/reworkd_platform/web/api/router.py` 和 `web/api/agent/views.py`，这会告诉你所有 agent HTTP endpoint。继续读 `web/api/agent/dependancies.py` 与 `agent_service/agent_service_provider.py`，理解每个请求如何先校验用户、创建 run/task 记录、选择 mock 或 OpenAI service。核心实现放在 `agent_service/open_ai_agent_service.py`，这里要重点看六个方法：`start_goal_agent`、`analyze_task_agent`、`execute_task_agent`、`create_tasks_agent`、`summarize_task_agent`、`chat`。

第四阶段读工具和数据层。工具从 `platform/reworkd_platform/web/api/agent/tools/tool.py` 开始，再读 `tools.py`、`open_ai_function.py`、`search.py`、`code.py`、`image.py`、`sidsearch.py`。重点问题是：工具如何声明 `description` 和 `arg_description`，如何被转换成 function schema，如何返回流式响应。数据层先读 `next/prisma/schema.prisma`，再读 `next/src/server/api/routers/agentRouter.ts`，这条线负责前端历史；后端读 `platform/reworkd_platform/db/models/agent.py`、`db/crud/agent.py`、`web/api/dependencies.py`，这条线负责 run 记录、loop 限制和 bearer token 到用户的映射。

可以后读的模块包括大部分 UI 组件、博客页面、静态页面、PDF 组件、动画组件、i18n 翻译资源和样式文件。它们对理解 agent 主流程不是第一优先级，但在修改界面时需要回来看。可以暂时跳过 `docs` 中的产品文档、赞助和社区相关内容、`scripts` 同步脚本、测试中的边缘 fixture，以及 `wikipedia_search.py`，因为该工具目前没有注册到 `get_external_tools()`。如果目标是修复生产问题，阅读顺序应按报错位置调整；但如果目标是系统学习，建议按“入口 -> 前端 agent 循环 -> FastAPI 路由 -> AgentService -> Tool -> DB/Auth -> UI 细节”的顺序继续下钻。
